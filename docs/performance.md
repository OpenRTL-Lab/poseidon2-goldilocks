# v1.1.0 性能测试方法与结果

[English](performance.en.md)

本文件定义并说明 Goldilocks Poseidon2 加速器的单任务延迟、稳态任务吞吐率和计算单元有效忙率，给出理想接口测试方法、正确性检查及实测结果：典型16上下文配置的单任务延迟为8,562 clk，稳态平均完成间隔为536 clk/任务，共享模乘有效忙率为88.0597%。

## 测试配置与计量条件

典型硬件配置是12个域元素状态（t12）、16个上下文槽位；槽位保存各在途任务状态并共享算术。测试工作负载为256个任务，不是256个硬件上下文。一次任务是完整12元素置换，任务标签用于关联请求与完成结果。
数据面每次握手携带完整状态，输入源立即提供、输出始终可接受，计算使能持续有效。
测试使用理想供数与收数时序，直接计量加速器的计算性能；协议背压和复位另以功能模式验证。
测试入口见 [复现指南](reproduction.md)，验证脚本分别运行单任务模式和饱和任务模式，并输出周期统计与计量日志。

## 延迟与吞吐分开计量

延迟等于同一任务的完成握手周期减去请求接受握手周期，不额外加1。
单任务测试始终只有一个任务在途；256个任务逐个完成，测得延迟均为8,562 clk。
饱和测试允许任务排队和上下文交织，任务延迟范围为8,562～17,122 clk，其中包含内部等待时间。

吞吐不由单任务延迟倒推。去掉暖机和尾批后，取标签16与标签240的完成时刻差；
两端对应相同轮转相位，中间224个任务间隔跨越120,064 clk。

| 指标 | 结果 |
| --- | --- |
| 单任务延迟 | 8,562 clk |
| 饱和任务延迟范围 | 8,562～17,122 clk |
| 稳态平均完成间隔 | 536 clk/任务 |
| 稳态吞吐率 | 1/536 ≈ 0.00186567 任务/clk |
| 500 MHz换算的单任务延迟 | 17.124 µs |
| 500 MHz换算的任务吞吐 | 约932,836任务/s |

表中的微秒和任务/秒由周期计数按500 MHz换算；仿真直接测量单位为clk，频率约束及setup数据见 [综合结果](synthesis-summary.md)。
同一算术流水线服务多个在途任务，因此吞吐与单任务延迟的倒数并不相等。

## 计算单元有效忙率

在同一120,064 clk窗口内，以验证环境 `WORK` 日志中对应有效操作的发射次数（不是产品输出端口）除以窗口周期数。
一拍只能发射一次的共享模乘，忙率直接反映有效工作发射；不把无效输入翻转或空流水线拍算作有效计算。
线性网络是并行网络，表中计的是相应逻辑操作类别的发射率，不是每个门/寄存器的切换率，也不是功耗。

| 操作类别 | 每任务有效次数 | 窗口有效发射clk | 窗口空闲clk | 忙率 |
| --- | --- | --- | --- | --- |
| 共享通用域模乘 | 472 | 105,728 | 14,336 | 88.0597% |
| 外部4×4块变换 | 9 | 2,016 | 118,048 | 1.6791% |
| 外部跨块同列合并 | 9 | 2,016 | 118,048 | 1.6791% |
| 内部全状态求和 | 22 | 4,928 | 115,136 | 4.1045% |
| 内部对角变换 | 22 | 4,928 | 115,136 | 4.1045% |

七次幂每元素需4次模乘，完整轮8×12个元素、部分轮22个元素，共118次七次幂、472次模乘。
已验证每个任务上述次数准确，不用整个仿真时长近似忙率。
本版本通过上下文交织共享模乘流水线，模乘有效忙率为88.0597%；线性层采用专用并行网络，面积约占43.72%，各类操作的发射率见上表。面积占比与有效操作发射率分别计量。

## 正确性及全测试周期数

重新生成SV和随包SV在独立构建中分别通过全部模式，两套结果一致。
每个正向模式均检查256任务×12元素=3072元素，逐元素等于C参考；Python完整矩阵模型另核对全部C向量。

| 模式 | 总测试clk | 不匹配元素 | 判定 |
| --- | --- | --- | --- |
| ideal | 137,218 | 0 | 通过 |
| protocol | 137,264 | 0 | 通过 |
| reset | 138,219 | 0 | 通过 |
| negative | 137,218 | 1 | 负控按预期检测到错误 |
| isolated | 2,192,128 | 0 | 通过 |
| disabled-buffer | 137,281 | 0 | 通过 |

表中的总测试clk用于记录完整测试运行，包含暖机、任务准入和尾批；单任务延迟与稳态吞吐按前文定义的独立窗口计量。
复现入口与原始计量日志由脚本在本地生成，见 [复现指南](reproduction.md)。
